Projeto de Acessibilidade Web

Este projeto foi desenvolvido como atividade acadêmica com foco em HTML semântico, acessibilidade digital e boas práticas de desenvolvimento web.

Objetivo da atividade

Criar um site com estrutura acessível, garantindo que todos os usuários, incluindo pessoas que utilizam leitores de tela, consigam navegar e compreender o conteúdo.

O que foi implementado

  • Estrutura HTML semântica (header, main, section, table)
  • Uso de atributos ARIA para acessibilidade
  • Formulário com validação e mensagens de erro
  • Tabela estruturada com cabeçalhos e scopes
  • Menu responsivo com botão mobile
  • Organização visual com CSS limpo e responsivo

Acessibilidade aplicada

O projeto foi desenvolvido respeitando princípios de acessibilidade, incluindo navegação por teclado, estrutura hierárquica correta e descrição de elementos importantes para leitores de tela.

Utilize o menu acima para navegar entre o formulário e a tabela de dados.
